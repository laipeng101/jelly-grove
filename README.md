# 果冻果园 · Jelly Grove

原创水果连连看，适合手机与电脑。水果由 SVG 绘制，音效由 Web Audio 合成，单文件版可以离线游玩。

[在线游玩](https://laipeng101.github.io/jelly-grove/) · [流转送达](https://laipeng101.github.io/jelly-grove/?play=lab)

## 玩法

依次选择两颗相同水果。连线最多转两次弯，可以绕棋盘外沿，不能穿过水果或石头。

- **果园漫游**逐关游玩。清盘、整局不用辅助、达到连消目标各得一星。
- **自由练习**可选难度，随时换盘。
- **限时鲜榨**在倒计时结束前尽量多得分。清盘获得额外分数，下一盘沿用剩余时间。
- **流转送达**按主题随机生成棋盘。每次消除推进轨道，在采收口配对目标水果可送达。可以提前查看轨道移动后的位置，也可免费撤销。

经典模式的提示、洗牌和撤销可免费使用。在果园漫游使用这些操作会失去“不用辅助”星，无路可连时的系统洗牌仍可得星。

键盘可用方向键移动、Enter 点选、H 提示、Z 撤销、空格或 Escape 暂停。经典模式用 S 洗牌，流转送达用 P 预览。

当前浏览器会按游玩入口保存进度。经典的三个模式分别保留棋局，流转送达单独存档。换设备、地址或切换在线与离线入口时，先在原入口的设置中导出对应进度，再在新入口导入。音效和动效可在设置中关闭。

在线游玩时，可在设置中下载离线版。用浏览器打开下载的 `果冻果园.html`，断网也能开盘。

## 开发

使用[发布工作流](.github/workflows/pages.yml)指定的 Node.js 版本。在仓库根目录运行 `npm ci`，再用 `npm run dev` 启动开发服务器。

[开发指南](docs/development.md)包含按改动选择验证、构建离线包和配置 GitHub Pages 的方法。
