# 果冻果园 · Jelly Grove

原创水果连连看，适合手机与电脑。水果由 SVG 绘制，音效由 Web Audio 合成，单文件版可以离线游玩。

[在线游玩](https://laipeng101.github.io/jelly-grove/) · [试玩流转送达](https://laipeng101.github.io/jelly-grove/?play=lab)

## 玩法

依次选择两颗相同水果。连线最多转两次弯，可以绕棋盘外沿，不能穿过水果或石头。

- **果园漫游**有 24 关。清盘、全局不用手动辅助、达到连消目标各得一星。
- **自由练习**有三档难度，随时换盘。
- **限时鲜榨**限时 120 秒。清盘加 500 分并自动续盘，计时从当前剩余时间继续。
- **流转送达**有六个随机主题。每次消除推进轨道，在采收口配对目标水果可送达；可以预览下一拍，也可免费撤销。每局按完成送达、不用解题提示和专属挑战计星。通关后可查看收获，自主选择下一主题或继续留在本盘。

经典模式的提示、洗牌和撤销可免费使用，影响“不用辅助”星。无路可连时的系统洗牌不扣星。详情见 [经典模式设计](DESIGN.md) 和 [流转送达规则与关卡蓝图](LEVEL-DESIGN.md)。

键盘可用方向键移动、Enter 点选、H 提示、Z 撤销、空格或 Escape 暂停。经典模式用 S 洗牌，流转送达用 P 预览。

进度保存在当前浏览器的游玩入口。经典三模式分别保留棋局，流转送达有独立试玩进度。换设备、地址或在在线与离线入口之间迁移时，在设置中导出和导入对应进度。音效与动效可在设置中关闭。

## 开发

在仓库根目录使用 Node.js 24，首次运行 `npm ci` 安装锁定的依赖。云端续作时先确认实际检出目录和目标提交。

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发服务器，打开终端显示的地址 |
| `npm run build` | TypeScript 检查、生产构建与单文件打包 |
| `npm run preview` | 预览已有生产构建 |
| `npm run verify` | 完整回归与构建，浏览器准备和专项见 [验证说明](VALIDATION.md) |

开发服务器忽略缓存和测试报告的写入。构建后可直接打开 `dist/果冻果园.html` 离线游玩。`dist/` 中的生产构建也可用于静态托管。

## GitHub Pages

[发布工作流](.github/workflows/pages.yml) 在 `main` 推送或手动调度时安装依赖、跑逻辑测试并构建，再将单文件包作为站点的 `index.html` 发布。仓库 Settings → Pages 的来源为 GitHub Actions。发布状态和网址以 Actions 部署任务为准。
