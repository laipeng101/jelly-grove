# 果冻果园 · Jelly Grove

一个可以慢慢玩、也值得练习的小小连连看。奶油与薄荷配色，原创 SVG 果冻水果，声音由 Web Audio 实时合成；没有外部字体、图片、账号、广告或付费依赖。

## 版本控制范围

仓库保留源码、测试、打包脚本、`public/` 静态资源、项目配置、`package-lock.json`、设计与验证文档，以及 `reference-evidence/` 中被设计文档引用的参考截图。

`.gitignore` 仅排除根目录下的 `node_modules/`、`dist/`、`.playwright-cli/`、`output/`，以及任意目录中的 `.DS_Store`。这些目录分别保存安装依赖、可重新生成的构建产物、本地浏览器操作记录，以及测试与审查过程输出。目录规则限定在项目根目录，避免误排除源码或测试夹具中的同名目录。

## 开始游玩

- 双击构建产物 `dist/果冻果园.html`，可直接离线游玩。
- 开发：`npm install` 后运行 `npm run dev`，打开终端显示的地址。手机与电脑在同一网络时可使用终端列出的 Network 地址。
- 正式构建：`npm run build`。`dist/` 可放到任何普通静态网站托管服务；其中 `果冻果园.html` 为独立离线版本。
- 预览构建：`npm run preview`。
- 验证规则与存档：`npm test`。
- 首次准备浏览器回归：`npx playwright install chromium`。
- 完整验证：`npm run verify`（逻辑测试、生产／离线构建、浏览器布局和交互回归）。仅复跑浏览器：`npm run test:browser`，需先运行构建。

手机自动显示紧凑对局：当前连消、续连时间、蓄能／双倍状态在棋盘上方，辅助操作在下方，各自独立占位。正常竖屏下完整棋盘同屏；极短屏或放大文字时只滚动棋盘，保留至少44px水果触控区域。点击“更多”可查看纪录、盘数和规则，并进入设置或帮助。

## 玩法

依次点击两颗相同水果。连线最多转两次弯，不能穿过水果或石头，可以沿棋盘外侧走一圈。

- **果园漫游**：24 关、4 个章节，逐步加入更大棋盘、留白、石头和下落，不限时。清空棋盘一星，整局不用手动辅助再得一星，达到关卡连消目标再得一星。
- **自由练习**：轻松、标准、进阶三档，持续生成新棋盘。进阶包含石头与下落。
- **限时鲜榨**：120 秒竞速。清空一盘额外获得 500 分，自动续上新棋盘，时间保持不变。
- **连消**：5.5 秒内继续消除可延续连消；每对基础 100 分，每级加 25 分，额外奖励最高 225 分。连消断掉不会结束游戏。
- **缤纷时刻**：消除积攒果汁，连消会更快蓄满；蓄满后 10 秒双倍得分，不改变连线规则。
- **辅助**：提示、洗牌、撤销可自由使用，影响本局“不用辅助”星。系统检测到无路可连时免费洗牌，不影响星级。撤销不会返还计时或已消耗的缤纷时刻。
- **暂停**：游戏时间、连消窗口、缤纷时刻一起暂停。打开弹窗或离开当前页面时也会暂停。

键盘：方向键在水果间移动、Enter 点选、H 提示、S 洗牌、Z 撤销、空格或 Escape 暂停。音效与动效可在设置中关闭。

## 新关卡试玩：流转送达

从桌面“新关卡试玩”或手机模式菜单进入独立试玩，也可在当前地址后加 `?play=lab`。原有24关、自由练习和限时模式继续可用。

- 六个主题对应新蓝图的第13–18关：到站配对、保留推进配对、提前开路、同色取舍、双轨调度和综合送达。每次换盘在主题约束内生成新的水果关系与解法。
- 成功消除一对后，轨道沿箭头转一格，空位一起移动；目标水果至少一颗在采收口并合法配对才算送达。可以消掉多余目标，但必须留够订单配额。
- 思考不限时，连消和果汁不会衰减。没有自动洗牌；走错后可以免费撤销到本盘起点。下一拍预览帮助看位置，不推荐配对。
- 三星分别对应通关、本盘不用解题提示、完成专属挑战。同一盘全部达成才算三星，撤销不扣星。解题提示逐层展开，提示标记在同盘重试后仍保留。
- “重试本盘”保留相同初盘；“换一盘”重新生成。试玩使用独立存档，并可在设置中单独导入导出。音画偏好与原模式共用。
- 正常手机竖屏保持完整棋盘同屏；文字放大或空间不足时允许滚动，保留水果触控区域，目标与操作仍可到达。
- 生成在内联Worker中完成，三秒内未得到合格棋盘时使用同标准验证的备用局，所有内容包含在离线HTML中。

完整24关蓝图、生成规则与审核要求见 [LEVEL-DESIGN.md](LEVEL-DESIGN.md)。其余十八关尚未实现。代理验证不能证明真人5–10分钟体验目标。

实现后的问题闭环、冻结标识和隔离审核证据见 [JOURNEY-VALIDATION.md](JOURNEY-VALIDATION.md)。

开发验证：`npm run verify`；六主题各100次生成基准：`npm run journey:benchmark`。`npm run journey:backups` 会重建受版本控制的备用局，属于关卡内容变更，需要重新构建并重做冻结审核。冻结与检查命令为 `npm run journey:freeze`、`npm run journey:check-freeze`。

## 原模式存档

三种模式分别保存当前局，包含棋盘、分数、关卡、计时与撤销历史。刷新后先显示暂停界面，点击继续。设置中可以导出、导入 JSON 进度备份；导入前有覆盖确认，并校验文件内容。

存档属于当前浏览器和地址。离线 HTML、localhost、局域网 IP、不同设备各自有独立存档；迁移时用导出／导入。浏览器禁用本地存储时游戏仍能玩，但需主动导出进度。

## 实现

- `src/engine.ts`：纯逻辑。路线枚举、建设性棋盘生成、关卡配置、下落、无解恢复。
- `src/game.ts`：消除结算、连消与竞速计时、棋局恢复；逻辑结算不依赖动画。
- `src/main.ts`：交互、模式切换、弹窗、快速点击缓冲与动效。
- `src/art.ts`：10 种原创矢量果冻水果与界面图标。
- `src/audio.ts`：轻量 Web Audio 和弦。
- `src/storage.ts`：版本化本地存档与导入校验。
- `src/style.css`：桌面、平板和手机布局，减少动效设置。
- `tests/`：独立 BFS 校验连线路径、关卡清盘与生成路径验证、障碍与下落、洗牌保真、竞速临界结算、存档校验。

完整构建无需运行时依赖。玩法设计依据见 `DESIGN.md`。
