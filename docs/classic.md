# 经典模式设计

## 玩法约束

- 超过连消时限后，连消次数归零，本局继续。
- 静态初盘须有解。玩家选择其他顺序或下落造成无路可连时，系统免费洗牌，保留水果数量与障碍。
- 暂停、打开弹窗或离开页面时冻结游戏计时、连消窗口和缤纷时刻的倒计时。撤销可恢复棋盘和得分，已消耗的游戏时间和缤纷时刻仍计入。恢复限时鲜榨棋局时先停在暂停状态。

## 手机布局

- 紧凑对局顶部保留模式、关卡或难度、更多和暂停。分数、剩余时间或对数、漫游连消目标、当前连消与续连时间条、蓄能或双倍剩余时间实时可见。纪录、规则和次要操作可从“更多”查看。
- 状态、反馈、棋盘和辅助操作各占独立空间。普通反馈预留两行，避免遮挡或挤动棋盘。保留棋盘形状、障碍、下落及外沿连线，棋盘四周预留 16 CSS 像素。
- 默认字号、有效视口达到 360×640 CSS 像素时，最大棋盘、实时状态和辅助操作完整同屏。水果及主要操作至少 44×44 CSS 像素，实时状态文字至少 12 CSS 像素。
- 视口变短、旋转或文字放大时重新适配，允许状态文字换行。空间不足时仅棋盘可滚动，状态和辅助操作留在屏内。保留浏览器双指缩放。

## 音效

- 高频反馈短而清楚。连消在有限音区变化，音量保持稳定。按消除前的水果快照选择音色，各水果共享旋律。
- 优先播放清盘反馈，其次是进入缤纷时刻，最后是普通消除。三种反馈都保留水果音色的起音。限时鲜榨清盘与最终结算分别提示，进入最后十秒时提醒一次。无法连线时不播放音效。
- 静音、暂停、开新局或进入后台时收束待播音效。音量滑杆松手试听，旧档缺少音量时使用默认值。
